MEASURED (cpeu_run/cpeu_order) resource model of the emitter: a wire holds an
affine form (const ^ raw subset ^ node-value subset); CX preserves the SPAN of
the 18 wire vectors, so the binding quantity is
    dim span { residue(O) : O a still-pending operand }
where residue(O) = O with the not-yet-computed node bits cleared.  This is a
hard lower bound on the wire count at that instant, and it is the packed
quantity (several node values on one wire count as one dimension).
  peak LIVE NODE VALUES over 300 component-DFS orders: 16
  peak DIM-SPAN of the same orders (i.e. after packing): 19
=> packing turns 16 live node values into 7 dimensions above the 12 raw bits.
   Budget is 18.  Gap at this point: 1 dimension.

MEASURED (cpeu_beam.py) beam search over node orders, objective = peak

  BW=200 seed 0            -> 18
  BW=1200 seeds 0,1,2,3    -> 18 (all four)
=> 18 is reachable but with ZERO slack: at the peak the 18 wires must be a
   basis of the residue span, so no wire is free for scratch and any three
   operands read by one gate must be linearly independent.

MEASURED (structural, follows from the model and confirmed in every run):
  CX is the only assembly instruction and it preserves the span exactly, so a
  raw bit can leave a data wire ONLY if it is duplicated on another wire or a
  nonlinear write lands on that wire.  The 12 data wires are therefore pinned
  for the whole circuit unless node values are hosted on them; the emitter's
  free scratch is the 6 ancillas plus whatever hosting it can arrange.

CONCLUSION (measured)
The emitter lever asked for works on the quantity it was aimed at: writing
each AND result straight onto the wire that accumulates the operand it feeds
takes the emitter from 15 cx/gate to 4.14 cx/gate, at or below the 4.4 target,
and it needs 178 RCCX-equivalents against a 138 floor.  It does not convert
into depth.  The single measured number that blocks < 258 at width 18:
  the accumulator emitter's DEPTH AT UNLIMITED WIDTH is 461 (opt2 = opt3,
  exact, 48 wires), against 127 for the same DAG emitted by cpet_wide with one
  wire per operand instance.  The cost of packing several node values per wire
  is a 3.6x longer dependence chain, because each accumulator must receive its
  node values in sequence on ONE wire while the unpacked emitter writes them
  on separate wires in parallel and XORs them with a balanced CX tree.
  Secondary blocking number: the emitter does not complete at width 18 at all;
  its first feasible width for the whole DAG is 36, and per cone 18 / 27 / 18
  / 35, because the depth-first drive holds one accumulator per recursion
  level while the 12 data wires cannot be freed by CX.
