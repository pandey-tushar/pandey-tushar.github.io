WHY NO PHASE-POLYNOMIAL / DIAGONAL METHOD CAN BE THE BOARD METHOD
  F's Walsh support is 4095/4096 (FACTS.md), so any CX+Rz phase-polynomial
  realisation needs ~4095 rotation terms and >= ~4095 CX.  Measured:
  qiskit Diagonal = 4094 CX.  The board's 557 CX (1st) and 348 CX (2nd)
  are 7x and 12x below that, so the leaders are NOT using a diagonal /
  Gray-path / parity-network construction.

WHAT 142/557 AND 166/348 IMPLY (arithmetic, using FACTS.md primitive costs
CCZ = 10 depth / 6 CX, Margolus = 7 depth / 3 CX)
  557 CX / 6 = 93 CCZ-equivalents, or 557/3 = 186 Margolus-equivalents.
  142 depth / 10 = 14 CCZ stages; 18 wires hold 6 disjoint CCZ per stage,
  6*14 = 84 ~ 93.  So entry 1 is ~90 three-qubit nonlinear gates packed
  ~6-wide over ~14 AND levels.
  348 CX / 6 = 58 CCZ-equivalents, 166/10 = 17 stages, 58/17 = 3.4 wide.
  With compute+phase+uncompute that is a network of ~45 (entry 1) and
  ~29 (entry 2) AND gates -- i.e. a multiplicative-complexity-class XAG
  for the WHOLE 12-input F, pebbled onto 6 ancillas.  For comparison the
  BDD-XAG above has 96 ANDs and cpee_results.txt reports 41 ANDs at
  AND-depth 3 for the eight cofactor-code bits.

CPEG LITERATURE TABLE -- predicted resources for n=12 inputs, m=6 clean

1. LHRS -- Soeken, Roetteler, Wiebe, De Micheli, "Hierarchical reversible
   logic synthesis using LUTs", DAC 2017; TCAD 38(9):1675-1688, 2019.
   https://dl.acm.org/doi/10.1145/3061639.3062261
   https://ieeexplore.ieee.org/document/8418797
   Qubits = n + #LUTs + #outputs (one line per LUT output, no reuse).
   Each k-LUT becomes one single-target gate, ESOP-synthesised: <= 2^(k-1)
   MCTs of <= k controls.  For F: the 96-AND XAG maps to ~25-30 4-LUTs, so
   qubits = 12 + 30 + 1 = 43 (not 18); forcing 18 needs the pebbling
   variant.  Cost: per 4-LUT, 8 MCT with <=4 controls, each C4X with a
   clean ancilla ~ 6 CCX = 36 CX / ~66 depth -> ~290 CX, ~530 depth per
   LUT; 30 LUTs forward ~ 8700 CX, ~16000 depth.  PREDICTION: >> 200.
2. Reversible pebbling game -- Meuli, Soeken, Roetteler, Bjorner, De
   Micheli, DATE 2019, arXiv:1904.02121.
   https://arxiv.org/abs/1904.02121
   SAT search for a pebbling of a DAG with a fixed number of pebbles
   (= qubits) minimising steps (= gate count).  It converts a qubit budget
   into a step count; it does not itself synthesise the network.  Measured
   analogue in this repo (cped_*): a 33-gate AND-DAG had NO schedule at
   K = 6..12 registers, 551 depth at K=14, 294 at K=26.  PREDICTION for a
   96-AND DAG at 6 pebbles: no schedule / astronomic steps.
3. XAG / multiplicative complexity -- Meuli, Soeken, Roetteler, De Micheli,
   "The role of multiplicative complexity in compiling low T-count oracle
   circuits", ICCAD 2019, arXiv:1908.01609. https://arxiv.org/abs/1908.01609
   T-count <= 4*c_and(f), ancillae = c_and(f) (one per AND), plus a
   SAT-based qubit/T trade-off.  Implemented as tweedledum xag_synth.
   MEASURED on the 96-AND BDD-XAG of F: 102 qubits, depth 1644, CX 1879.
   For width 18 one needs c_and <= 5 live -> requires (2).  If the board's
   557 CX / 142 depth is ~90 three-qubit gates, the implied XAG has
   c_and(F) ~ 45 with AND-depth ~14 after pebbling.  PREDICTION: this is
   the only family whose gate budget matches the board.
4. Bennett space-time pebbling -- Bennett, SIAM J. Comput. 18(4), 1989;
   Levine-Sherman 1990; Kralovic 2001.
   https://mathweb.ucsd.edu/~sbuss/CourseWeb/Math268_2013W/Bennett_Tradeoffs.pdf
   A DAG pebblable with s pebbles in t steps is reversibly pebblable in
   t^(1+eps)/s^eps steps with eps*(2^(1/eps)-1)*s*log(t/s) pebbles.
   For a 96-node path DAG at s=6: ~96^(1+1/5) = 96^1.2 ~ 230 steps, i.e.
   ~230 Toffoli ~ 1380 CX, depth ~2500.  PREDICTION: >> 200.
5. ESOP phase synthesis -- tweedledum pkrm/pprm/esop_phase_synth, and
   qiskit PhaseOracle / BooleanExpression (qiskit 2.x synthesises an ESOP
   itself: qiskit/synthesis/boolean/boolean_expression_synth.py).
   MEASURED: 28955/19943 at width 12 (exact), 13411/7267 at width 18
   (exact), 27150/19846 (tweedledum PKRM, width 13).  PREDICTION: ruled
   out; F's minimal ESOP found here is 83 cubes / 790 literals, and a
   790-literal cover cannot fit in 557 CX.
6. QROM / unary iteration -- Babbush et al., PRX 8, 041015 (2018),
   arXiv:1805.03662; SelectSwap: Low, Kliuchnikov, Schaeffer,
   arXiv:1812.00954, Quantum 8, 1375 (2024).
   https://arxiv.org/abs/1805.03662  https://arxiv.org/abs/1812.00954
   QROM over L=2^12 addresses with b=1 output bit: L-1 = 4095 Toffoli,
   ceil(log2 L)-1 = 11 clean ancillas; Toffoli depth ~4095 -> ~24500 CX.
   SelectSwap with lambda extra ancillas: Toffoli ~ L/lambda + lambda*b;
   at 6 ancillas lambda = 4 -> 1024 + 4 = 1028 Toffoli ~ 6200 CX.
   PREDICTION: >> 200.  Only a cofactor-address QROM (6 address bits,
   F has 11 distinct cofactors) gets near: 63 Toffoli for unary iteration
   over 64 addresses + 5 ancillas = 378 CX, but the 4-bit code output
   needs 4 more wires (12+5+4 = 21 > 18).
7. Diagonal-unitary with ancillas -- Sun, Tian, Yang, Yuan, Zhang,
   "Asymptotically optimal circuit depth for quantum state preparation and
   general unitary synthesis", TCAD 2023, arXiv:2108.06150.
   https://arxiv.org/abs/2108.06150
   Depth O~(2^n/(n+m) + n), size O(2^n).  n=12, m=6: 4096/18 + 12 = 240
   depth, ~4096 gates.  MEASURED ancilla-free analogue (qiskit Diagonal):
   8170 depth / 4094 CX, i.e. 24x the 2^n/n = 341 leading term.
   Gray-path framework, arXiv:2606.17589 (2026): Rz and CNOT depth
   O(2^n/n) = O(341) ancilla-free, CX count Theta(2^n) = 4096.
   https://arxiv.org/abs/2606.17589
   PREDICTION: depth maybe ~230-5500 but CX >= ~4000 in all cases, so the
   board's 348-557 CX rules the whole family out (see Walsh support note).
8. General-oracle size/depth/ancilla optimum -- Nie, Zi, "Nearly optimal
   quantum circuits for Boolean oracles", arXiv:2607.28402 (2026).
   https://arxiv.org/abs/2607.28402
   Total Boolean function, output size b, 1 <= m <= Theta(2^n/n) ancilla:
   size O(b*2^n/log(n+m)), depth O(b*2^n/(n+m)).
   n=12, b=1, m=6: size O(4096/log2(18)) = O(4096/4.17) = O(982),
   depth O(4096/18) = O(228).  Asymptotically optimal up to log factors.
   PREDICTION: 142 depth is BELOW the constant-1 evaluation of the optimal
   general-function bound, so the board is exploiting F's structure
   (GF(2) rank 10, 11 distinct cofactors), not a generic truth-table
   method.
9. Optimal T/Toffoli depth from the ANF -- "Optimal T depth quantum
   circuits for implementing arbitrary Boolean functions", arXiv:2506.01542
   (2025).  https://arxiv.org/abs/2506.01542
   Toffoli (and T) depth exactly ceil(log2 k) for algebraic degree k.
   F has degree 12 -> Toffoli depth 4.  But the construction materialises
   the ANF monomials in parallel: F has 886 monomials (216 in the best
   affine basis), so ~900 ancillas.  PREDICTION: depth ~50 at width ~900;
   useless at 18, but it is the reason a low-depth answer exists at all.
