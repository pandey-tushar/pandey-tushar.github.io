  RCCX -> RCCX through control slot b  13 (+6 per level)
  RCCX -> RCCX through the target      12 (+5 per extra write on one wire)
  k-literal AND tree, k = 2/3/4/5/6     7 / 11 / 13 / 15 / 17
  RC3X 13/6   CCZ 10/6   CZ 3/1   5 CZ on disjoint pairs 3/5

  MIRROR BLOCK cost, measured on mock blocks C ; CZ ; C^-1 :
    forward 7  -> block 15      forward 11 -> block 23
    forward 15 -> block 31      forward 17 -> block 35 (also with 5 CZ: 35)
    i.e. block = 2*forward + 1, and extra parallel CZ legs are free.

  Whole D2 program (cpec_d2nl.py): 33 nonlinear gates, 12 CX, 5 CZ legs,

  IT DOES NOT FIT WIDTH 18 -- this is the binding constraint, measured:
    peak simultaneously live node values                 16
    peak live total (node values + still-needed raw bits) 18
    distinct node values created                          45
    zero-initialised registers available                   6
  The allocator fails at the 16th node ("no zero wire").  A wire can host a
  fresh value only if it provably holds 0: an untouched ancilla (6 of them)
  or a wire explicitly uncomputed.  A data wire that hosts a nonlinear value
  v becomes x_i ^ v, and recovering v as a control needs x_i, which after
  hosting is in no other wire's span (the twelve data wires were a basis) --
  so data wires can carry affine forms for free but not usable nonlinear
  intermediates.  D2 alone at AND-depth 2 needs 16 registers for nonlinear
  values; the machine has 6.

  Targets from the brief, status:
    R1 <= 30   NOT REACHED (shipped 43; its AND-depth is already 3 and its
               forward floor from that AND-depth is 15 -> block 31, but the
               x-axis accumulator takes 3 serial writes with 3 registers)
    R2t <= 28  NOT REACHED (shipped 39, AND-depth 3, floor 31)
    D1 <= 40   NOT REACHED (shipped 71, AND-depth 4, floor 39)
    D2 <= 45   NOT REACHED at width 18 (AND-depth-2 form exists and is
               verified, needs 16 registers)
    LEFT as one rank-5 staircase block: NOT REACHED.  Measured obstruction:
    a rank-r block needs r x-factor wires and r y-factor wires live at the
    CZ plus the scratch of both factor trees.  For the merged rank-2 block
    R1^R2t the two axes need 2 outputs + 2 scratch each = 8 registers; for
    a rank-5 LEFT or D2 block the x side alone peaks at 13-14 live values
    (measured with cpec_core.peak_width on the hand-built netlists).

BINDING CONSTRAINT (measured)
  1. Six zero-initialised registers.  Data wires can carry affine forms
     (CX-reachable, free) but not usable nonlinear values.
  2. Every shape's 12-variable ANF has x-degree 6 and y-degree 6 (measured
     above), and every basis of every shape's column space contains a
     degree-6 element (measured above), so every CZ leg needs a degree-6
     factor, whose minimum forward depth is 17 from the measured chaining
     costs -> minimum block depth 35 -> four blocks >= 140 before any
     scheduling loss.
  3. Reducing the AND-depth is what would buy the remaining 120 layers, and
     it is exactly what width forbids: the verified AND-depth-2 D2 needs 16
     live nonlinear registers against 6.  Number that proves it:
         D2 AND-depth-2 program, peak live node values = 16, registers = 6
         (shipped D2 runs the same shape at AND-depth 8 and depth 125).

STEP C2 -- WHAT A 6-REGISTER LEG ARCHITECTURE COSTS (cpec_walk2.py, exact)
  In the only width-legal shape (one or two CARRIER wires per side walking
  through the atoms, phase legs = CZ between an x carrier and a y carrier),
  a carrier hop costs one Margolus WRITE per rank-1 term of the delta, and a
  second write onto the same wire starts only after the first finishes
  (measured +5 layers).  Exhaustive search over products of one "outer"
  factor (cy = ~y5~y4, dy = ~y5y4, ~y5) and one or two "inner" factors
  (t = y3~y2, u = y3y2, v = ~y3y2, s = ~y3~y2, p = y1y0, q = ~y1~y0,
  r = y1~y0, ~y3, y1, y0, y1^y0, ~y1, ~p, 1) gives, for D2's y atoms:
    build YD1 3 writes, YD2 3, YD3 4, YD4 2, YD5 3
    hops YD1->YD2 1, YD2->YD3 2, YD3->YD4 2, YD4->YD5 3
  ONE y carrier walking YD1..YD5 = 3+1+2+2+3 = 11 writes
      -> forward >= 7 + 5*10 = 57      -> D2 block >= 115  (shipped 125)
  TWO y carriers, split {1,2,3} / {4,5} = 6 and 5 writes
      -> forward >= 7 + 5*5 = 32       -> D2 block >= 65
  but two carriers per side needs, measured on the verified factorisation:
    x side : c (=x5~x4) or k (=x5~x3), h (=~G2~G1), the S'/W2/I3 chain,
             2 carriers                            = 5 registers
    y side : cy, dy, one inner helper, 2 carriers  = 5 registers
    = 10 registers against 6 ancillas.
  DATA-WIRE HOSTING, exactly how much it buys (all four facts verified by
  the identity, not estimated):
    x4 : free once c is built; every XD term carries c = x5~x4 and
         c.x4 = 0, so a value hosted on x4 is exact in every such term --
         ONE free register.  XD_5 = {32,48} has no ~x4 factor, so it must
         be fired before x4 is taken.
    y5 : free once cy and dy are built; every Y term carries cy, dy or ~y5
         and cy.y5 = dy.y5 = ~y5.y5 = 0 -- ONE free register.
    x5 : c.x5 = c is NOT 0, so hosting there costs one correcting Margolus
         per use (3 uses measured on the x side).
    y4 : cy.y4 = 0 but dy.y4 = dy, so y4 only hosts helpers used in
         cy-terms.
  So the usable register count is 6 ancillas + 2 clean data hosts = 8,
  against the 10 the two-carrier D2 needs; the one-carrier version fits and
  floors at 115.  The same accounting on LEFT (rank 5, same shape) gives a
  one-carrier floor of the same order, so the four-shape total in this
  architecture floors at roughly 250 and the shipped 270 is within 8% of it.

CONCLUSION
  Target depth < 150 NOT REACHED.  The route is blocked, with numbers:
  (a) every shape needs a degree-6 phase factor (measured 12-var ANF), whose
      minimum forward depth is 17 (measured chaining), so four mirror
      blocks cannot beat 140 even before width;
  (b) the AND-depth-2 form that would reach that bound exists and is exact
      (D2, verified 0/4096) but needs 16 simultaneously live nonlinear
      values against 6 zero-initialised registers + 2 clean data hosts;
  (c) forced onto one carrier per side, the carrier takes 11 Margolus writes
      for D2's five legs at +5 layers each, giving forward >= 57 and
      D2 block >= 115 -- i.e. the shipped D2 (125) is already within 10
      layers of the floor of the only width-legal architecture.
  THE NUMBER THAT PROVES IT: D2 at AND-depth 2 needs 16 live nonlinear
  registers; the machine has 6 (+2 clean data hosts).  At 6 the same shape
  costs >= 115 of the 150 budget on its own.
  HONEST SCOPE OF THAT CLAIM: it bounds THIS route -- mirror blocks whose
  phase legs are CZ between an x carrier and a y carrier, with nonlinear
  values only on the 6 ancillas plus the two data wires whose residue is
  killed by an outer factor.  The leaderboard entry at 142 / 557 cx / width
  18 shows some architecture beats 150, and its cx count (557 against our
  516, i.e. about 186 RCCX-equivalents against our 118) says it spends many
  more gates spread over many more wires than this route allows; what those
  extra wires carry was NOT MEASURED here.
