Lesson 1: A surface code patch

Nine physical qubits in a 3 by 3 grid hold one logical qubit. An encoder spreads |0⟩ over all nine, and eight checks (four X, four Z) watch for errors. Pick an error next to the Play button to see which checks fire.

Patches and gate layers

The ideal logical circuit

Run it live

Step by step

  1. encode A. CNOT q0 → q1 starts copying q0 along the top row. H on q4, q5, q6, q7 makes them the sources of the X checks.
  2. encode A. CNOT q0 → q2 finishes the copy. Had q0 been |1⟩, the top row would now carry X on all three qubits: that is X​L, the logical flip.
  3. encode A. The sources fan out: CNOT q4 → q0, q5 → q2.
  4. encode A. The sources fan out: CNOT q4 → q1, q7 → q0.
  5. encode A. The sources fan out: CNOT q4 → q3, q7 → q1.
  6. encode A. The sources fan out: CNOT q6 → q3, q7 → q2.
  7. encode A. The sources fan out: CNOT q7 → q3.
  8. encode A. CNOT q7 → q8 completes the fan-out: all eight checks hold and A is |0⟩​L. Whatever state q0 starts in, the encoder makes it the logical state.
  9. measure. Every qubit is measured in Z. Only the checks that are Z parities can still be read.
