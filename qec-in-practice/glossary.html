Each has one plain sentence and one technical sentence, with a link to the page that introduces it.

Qubit

The basic unit of a quantum computer: like a bit it reads 0 or 1, but before it is read it can hold a mix of both.

A two-level quantum system with state a|0⟩ + b|1⟩, where |a|2 + |b|2 = 1.

Bit flip

An error that swaps 0 and 1.

The Pauli operator X, which sends |0⟩ to |1⟩ and |1⟩ to |0⟩. See The repetition code.

Phase flip

An error that leaves 0 and 1 alone but changes how they combine in a mix, which a reading of 0 or 1 cannot show.

The Pauli operator Z, which leaves |0⟩ alone and sends |1⟩ to −|1⟩; Y = iXZ is both flips at once. See The repetition code.

Parity check, stabilizer

A question asked of a small group of qubits, "do you agree?", whose answer never reveals the stored value.

A product of Pauli operators, Z on neighbours in the repetition code and X or Z on the corners of a tile in the surface code, that is +1 on every code state; the group the checks generate is the stabilizer. See The repetition code.

Syndrome

The list of answers from one round of checks.

The vector of measured check outcomes, each +1 or −1, usually written as bits with 1 for −1. See The repetition code.

Fired

A check fires when it reports a disagreement.

A check has fired when it reads −1, which happens when an odd number of its qubits carry an error that anticommutes with it. See Errors, syndromes and decoding.

Distance

The fewest errors that can change the stored information without any check noticing.

The smallest weight of a logical operator; a code of distance d is guaranteed to correct (d − 1)/2 errors for odd d. See The repetition code.

Logical qubit

The one protected qubit that a code stores across many physical qubits.

The encoded qubit, acted on by logical operators XL and ZL that commute with every check but are not products of checks. See Lesson 1.

Patch

A square block of qubits that together hold one logical qubit.

A rotated surface code of distance d: d × d data qubits with X and Z checks on alternating tiles and two-qubit checks on the edges; at d = 3 it has nine data qubits and eight checks. See Lesson 1.

Decoder

The program that reads the fired checks and guesses which errors to undo.

A map from syndrome to correction; it succeeds when error and correction together form a product of checks, and fails when they form a logical operator. See Errors, syndromes and decoding.

Union-find decoder

A fast decoder that grows regions around fired checks until each region can be explained from inside, then corrects within each region.

The decoder of Delfosse and Nickerson: clusters with an odd number of fired checks grow by half edges and merge, then a spanning forest of each cluster is peeled to give the correction, in close to linear time. See Errors, syndromes and decoding.

Matching decoder

A slower and more accurate decoder that looks for the shortest way to pair up all the fired checks.

Minimum-weight perfect matching on the graph of checks; the threshold lesson compares union-find with reference results from pymatching. See The threshold.

Threshold

The error rate below which a bigger code helps and above which it hurts.

The physical error rate that the crossings of the curves of logical error rate for different distances approach as the distance grows; for small codes the crossing sits lower. It depends on the code, the noise model and the decoder together. See The threshold.

Lambda

How many times less often the code fails each time the patch grows by one ring of qubits.

The factor by which the logical error rate falls when d grows by 2, read from a straight-line fit of the log of the rate against d. See The threshold.

Bell pair

Two qubits whose readouts in Z always agree, although each reading on its own is random.

The state (|00⟩ + |11⟩)/√2; the course makes a logical Bell pair of two patches with a logical CNOT in lesson 2 and with a merge and split on the lattice surgery page. See Lesson 2.

T state

A particular one-qubit state, made by H and then T; read in X it gives 1 in about 14.6% of shots.

T|+⟩ = (|0⟩ + eiπ/4|1⟩)/√2, for which the X readout gives 1 with probability sin2(π/8), about 0.146. See Lesson 3.

Teleportation

Moving a qubit's state onto another qubit with a shared Bell pair and two measured bits, without sending the qubit itself.

A CNOT from the source to one half of a Bell pair, the source read in X and that half in Z, then XM2 ZM1 on the other half, as drawn in lesson 4. See Lesson 4.

Lattice surgery

Joining two patches along an edge with new checks and then separating them, to measure a joint property of both.

Merging two patches through a seam measures ZL ZL (or XL XL, with the patches stacked) as the product of the new seam checks; splitting restores the two patches up to a Pauli frame. See Lattice surgery.

Pauli frame

A record of corrections that is kept in software instead of being applied to the qubits.

The Pauli operators implied by measured outcomes, such as the corrections after a split, tracked classically and folded into later readouts; the lattice surgery figure applies them so they can be seen. See Lattice surgery.
